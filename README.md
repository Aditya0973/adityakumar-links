## ✨ Features

- 🎨 **Neo-Brutalist Aesthetic**: Warm cream palette (`#FFFCF3`), high-contrast dark accents (`#1E1E1E`), and electric orange (`#FD601A`) brutalist shadows.
- ✳️ **Exact Figma Vector Starburst**: Dynamic 8-pointed starburst in headline with color shift (`PR✳️DUCT DESIGNER.`).
- ⚡ **Looping Autonomous Skill Badges**:
  - *Typography*: Typewriter sequence.
  - *Color Theory*: Continuous left-to-right & right-to-left color-fill wave.
  - *Interaction Design*: Word-swapping motion.
  - *Logo Design*: Vector star pop-in.
  - *3D Modeling*: Dynamic depth glow.
  - *Vibecoding*: Terminal typing micro-loop.
- 🎯 **Interactive 5 Core Link Showcase**:
  1. **Portfolio Hub**: Dynamic particle interaction.
  2. **Crafted Co.**: Digital Logistics mini-game (pack and dispatch trucks with live products).
  3. **Behance Visual Lab**: Interactive 3D donut with 4 flavor shaders & wireframe mode.
  4. **GitHub Repos**: 8-bit Commit Miner game.
  5. **LinkedIn Persona**: Endorsement cannon & Corporate Jargon generator.
- 📄 **Resume Card**: Direct in-browser viewing and PDF download.
- 🎨 **Spray Paint Canvas**: Background spray-can painter with 3 gradient palettes and clearing tool.
- 🕹️ **Draggable Physics Stickers**: Kinetic, throwable neo-brutalist badges with momentum and auto-hinting loop.
- 🔊 **8-Bit Retro Sound Effects**: Web Audio synthesized clicks, pops, and chimes.
- 📱 **Fully Responsive**: Optimized for both PC (Bento & Feed views) and mobile devices.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Neo-Brutalist Utilities
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVGs
- **Deployment**: Vercel-ready

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Aditya0973/adityakumar-links.git
cd adityakumar-links
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
